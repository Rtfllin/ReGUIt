# ReGUIt

[中文说明](README.zh-CN.md)

**ReGUIt** is a GUI multi-boot manager for UEFI/GPT systems.

> Boot, redefined.

ReGUIt focuses on a graphical interface, multilingual support, customization,
and an optimized interaction experience—making multi-boot setup more intuitive,
friendly, and reliable.

## Status

**Early development / experimental.** Not yet production-ready.

Do not use ReGUIt as your only bootloader on a production machine yet.
Always keep a recovery method available.

## Goals

- GUI boot menu for UEFI/GPT systems
- Automatic OS discovery
- Multilingual UI
- Customizable themes and configuration
- Optimized keyboard/mouse interaction


## Non-goals

- Forcibly replacing existing bootloaders
- Modifying OS installations without explicit confirmation
- Supporting legacy BIOS/MBR as a primary target

## Safety
